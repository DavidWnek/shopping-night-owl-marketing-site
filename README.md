# Shopping Night Owl — marketing site

Static landing page and privacy policy for the Shopping Night Owl Chrome extension.
Served by GitHub Pages from the root of the `main` branch.

- `index.html` — landing page
- `privacy.html` — privacy policy (linked from the Chrome Web Store listing)
- `img/` — screenshots and icon, generated in the extension repo by `scripts/store_shots.js` + `scripts/store_compose.py`
